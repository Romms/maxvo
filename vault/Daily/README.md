# Daily notes

One note per day, named `YYYY-MM-DD.md`, created by the `morning-checkin` and `evening-checkin`
skills — see `docs/daily-rituals.md`. Structure:

```markdown
## Ранок
- Пріоритет дня: ...
- Перший крок: ...
- Фіксовані зустрічі: ...
- Енергія: ...

## Вечір
- Пріоритет виконано: так / частково / ні
- Що зроблено сьогодні: ...
- Що лишилось відкритим: ... (-> Open Loops / Inbox)
- Нові ідеї: ... (-> Ideas)
- Завтрашній пріоритет (чернетка): ...
- Енергія / криз: ...
```
