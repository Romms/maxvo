# Health

Постійна відповідальність без фінішу — підтримувати стан, а не "завершити" щось. "В нормі" означає:
тиск у межах норми, немає симптомів, яким немає пояснення, регулярні тренування 2-3 рази/тиждень.

Профіль тіла (антропометрія, постійні обмеження — канонічне місце): [[Профіль]].
Журнал тиску: [[Blood Pressure]].
Програма й журнал тренувань: [[Тренування]].
Харчування й гідратація: [[Харчування]].
Головний біль — щоденник для лікаря: [[Головний біль — щоденник спостережень]],
дослідження зв'язку з препаратом: [[Бупропіон і головний біль — дослідження]].
